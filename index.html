How to play

10 guesses

Crack the secret code in 10 guesses or fewer. Each digit is 0 to 9, and a code can start with 0.

Make a guess

Tap digits on the keypad to fill each space, then tap Enter. ⌫ deletes the last digit.

Read the lights

  • Green: a right digit in the right spot
  • Orange: a right digit in the wrong spot
  • Off: a digit that isn't in the code

The lights are shuffled. They tell you how many digits are right, not which ones.

Cross out

Tap ✕ Cross out, then a digit, to put a red X on it as a reminder. Do the same again to clear it.

Modes

Easy: 4 digits with no repeats. Hard: 4, 5 or 6 digits, and digits can repeat. Each digit in the code lights up only one light, so if the code is 1123 and you guess 1111, you get 2 green and 2 off.

Winning

All green cracks the code. If you're out of guesses, the code is revealed. The timer starts on your first tap, and Stats tracks your streaks, wins and best times.
